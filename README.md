# Dotfiles

A collection of configs and scripts, managed with [GNU Stow](https://www.gnu.org/software/stow/).

## Setup Scripts

- **`install.sh`** — Installs pacman packages from `pkglist.txt`, AUR packages from `aur-pkglist.txt` (via `yay`), then runs `stow */` to symlink every config directory into place.
- **`save_package.sh`** — Snapshots your currently installed packages: `pacman -Qqe` → `pkglist.txt` (explicitly installed), `pacman -Qqem` → `aur-pkglist.txt` (foreign/AUR packages). Run this before committing to keep package lists current.
- **`pkglist.txt`** — Generated list of explicitly installed pacman packages (output of `save_package.sh`, `pacman -Qqe`).
- **`installed_package.txt`** — Generated by `scripts/.local/bin/get-package.sh` (`pacman -Qq`) — a full list of _all_ installed packages, including dependencies. This overlaps with `pkglist.txt`/`aur-pkglist.txt` and isn't used anywhere else (not read by `install.sh`), so it looks like redundant/dead output — worth deciding whether to keep both scripts or consolidate into just `save_package.sh`.

## Application Configs (stowed)

- **`hypr`** — [Hyprland](https://hyprland.org/) config — the Wayland compositor/window manager itself (keybinds, monitors, window rules, startup apps).
- **`waybar`** — Status bar for Wayland compositors like Hyprland (workspaces, clock, system tray, etc.).
- **`rofi`** — Application launcher / menu (app launching, window switching, possibly power menu).
- **`dunst`** — Lightweight notification daemon (popup notification styling and behavior).
- **`kitty`** — GPU-accelerated terminal emulator config (colors, font, keybindings).
- **`zsh`** — Z shell config (`.zshrc`, aliases, prompt, plugins).
- **`nvim`** — Neovim editor config (plugins, keymaps, LSP setup, etc.).
- **`lazygit`** — Config for [lazygit](https://github.com/jesseduffield/lazygit), a terminal UI for git commands.
- **`fcitx5`** — Input method framework config, typically used for typing non-Latin scripts (Chinese, Japanese, Korean, etc.).
- **`gtk`** — GTK theme/settings (fonts, icon theme, widget theme) for GTK-based apps.
- **`nwg-look`** — Config for [nwg-look](https://github.com/nwg-piotr/nwg-look), a GTK theme configuration tool built for wlroots-based Wayland compositors.
- **`qalculate`** — Config for [Qalculate!](https://qalculate.github.io/), a desktop calculator app.

## Other

- **`scripts`** — Personal hand-written utility scripts, including:
  - `auto-upload-config.sh` — likely syncs/uploads these dotfiles somewhere (backup or remote repo)
  - `color-picker.sh` — color picker, bound to `SUPER+SHIFT+C` in Hyprland
  - `get-package.sh` — dumps _all_ installed packages (`pacman -Qq`, includes dependencies) to `installed_package.txt`; overlaps with `save_package.sh` below
  - `open-calc.sh` — opens calculator, bound to `SUPER+C`
  - `open-emoji.sh` — emoji picker, bound to `SUPER+code:60` (`SUPER + '.'`)
  - `open-menu.sh` — app launcher/menu, bound to `SUPER+Space`
  - `open-tab.sh` — used as an `Alt+Tab` window-switcher replacement
  - `powermenu.sh` — shutdown/reboot/lock menu, bound to the power button (`XF86PowerOff`), works even when the input inhibitor is active
  - `reload-waybar.sh` — restarts waybar, bound to `SUPER+SHIFT+B`
  - `translator.py` — translation helper script
  - `region.json` — likely config/data used by one of the above scripts (e.g. screenshot region or color-picker settings)
  - `uv`, `uvx` — the [uv](https://github.com/astral-sh/uv) Python package manager binaries/symlinks
  - `zmk` — symlink, likely related to [ZMK](https://zmk.dev/) keyboard firmware config
  - `README.md` — its own local documentation for this scripts folder
- **`yay`** — Config directory for the `yay` AUR helper; currently near-empty (yay doesn't store much config by default).
